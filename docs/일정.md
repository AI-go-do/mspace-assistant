## 다른 레포에 기대는 것
- **예약 코어 (지영):** v0.1(11/2–11/5)에 예약 생성·취소·퇴실·내 예약 API가 나와요. 그전에는 요구사항 명세의 경로로 가짜 서버(WireMock)를 만들어 개발해요
- **빈 시간 조회 API:** `GET /api/rooms/availability?date=`로 정해졌어요(core 브랜치 `feat/7-room-availability`). 자정을 넘기는 예약은 시작 날짜만 조회하고 나머지는 예약 결과로 판단해요 (11/2 지영님과 합의)
- **멱등 키:** 합의됨(11/2). core가 `Idempotency-Key`를 받는 PR을 11/4까지 올려요(내 예약·취소 다음). M2 #11에서 붙여요
- **내 예약 API:** 비서가 제안한 응답 모양 그대로 11/3 core PR
- **비서용 JWT scope:** 로그인 붙일 때 지영·재웅이 정해요. 방향(학생 토큰 그대로, `created_via`는 scope로, 비서 토큰은 관리자 API 차단)은 합의됨
- **배포 (재웅):** core와 같은 방식(Dockerfile, Actions, GHCR, `agent` 자리)으로 맞춰요
